ANTEPRIMA SUL COMPUTER
1. Estrai tutto lo ZIP.
2. Apri index.html con Chrome, Edge o Firefox.
3. Visita le altre pagine usando il menu.
Per visualizzare i font originali Google e la mappa serve Internet.

PUBBLICAZIONE COME SECONDO SITO SU GITHUB PAGES
1. Accedi a GitHub e crea un NUOVO repository, per esempio campania-service-verde.
2. Scegli Public se utilizzi GitHub Pages con un account gratuito.
3. Seleziona Add file > Upload files.
4. Carica tutto il contenuto della cartella estratta, inclusa images.
   index.html, style.css e script.js devono essere nella radice del repository.
   Non caricare soltanto lo ZIP e non mettere index.html in una sottocartella.
5. Conferma con Commit changes sul branch main.
6. Apri Settings > Pages.
7. In Build and deployment seleziona Deploy from a branch.
8. Seleziona main e / (root), poi Save.
9. Attendi che GitHub Pages mostri il link del nuovo sito.

Se il repository si chiama campania-service-verde, il link sarà:
https://michelefeola-prog.github.io/campania-service-verde/
Il link è un esempio: diventa attivo solo dopo la pubblicazione.

Il repository originale campania-service resta separato.
Puoi così mostrare entrambi i siti con due indirizzi diversi.
Non sono necessarie installazioni, npm o compilazioni.
